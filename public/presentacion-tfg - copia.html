El núcleo del proyecto

OCR con Google Cloud Vision

Pipeline

  • Imagen → base64 → GCV API
  • DOCUMENT_TEXT_DETECTION
  • Hint de idioma: español (es)
  • Regex parsing del texto crudo
  • Devuelve array de líneas estructuradas

El cliente revisa y corrige las líneas antes de confirmar. El importe total se recalcula en tiempo real.

Respuesta parseada

// Cada línea del ticket
{
  "cantidad": 2,
  "concepto": "Plato del día",
  "importe": 18.50
}

// importe_ticket (total)
"total": 37.00

Robustez del sistema

Seguridad y validación

FormRequest classes

Validación servidor en clases dedicadas (app/Http/Requests/). JSON uniforme: {ok, mensaje} en todos los errores 422.

Validación en tiempo real

JS blur/input: DNI/NIE/CIF algoritmo módulo 23, horarios de reserva, formatos de teléfono y email. Antes del envío al servidor.

Auth middleware

Panel de administración protegido por autenticación Laravel. Rutas con middleware('auth'). Sesiones seguras.

Transacciones DB

DB::beginTransaction() en solicitudes. lockForUpdate() para numeración de facturas sin colisiones.

13 / 16

Sin intervención manual

Automatizaciones

Numeración automática

Serie MW-2025 con padding a 4 dígitos. Bloqueo optimista para concurrencia segura.

Generación de PDF

DomPDF desde plantilla Blade. Almacenado en storage/app/public/facturas/ y accesible por URL firmada.

Email con PDF

Laravel Mail + Gmail SMTP. Cola de base de datos para no bloquear la respuesta HTTP al cliente.

El fallo del PDF no bloquea la solicitud. El registro ya está guardado y el PDF se puede regenerar desde el panel admin.
