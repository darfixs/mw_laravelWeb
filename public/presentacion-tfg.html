Decisión técnica clave

OCR — Tesseract vs Google Cloud Vision

Tesseract OSS — descartado

Requiere preprocesamiento de imagen
Baja precisión en tickets físicos reales
Sensible a rotación, contraste, ruido
Tiempo de configuración alto
Sin comprensión semántica del texto

Google Cloud Vision — elegido

DOCUMENT_TEXT_DETECTION
Sin preprocesamiento — tickets físicos reales
Hint de idioma: español nativo
Integración en < 20 líneas de código
Timeout configurable · Fiabilidad empresarial

Validación en dos capas

Seguridad y validaciones

Capa 1 — Cliente (JavaScript) blur / input events · tiempo real
Teléfono: regex /^[6789]\d{8}$/
Horario reserva por día de semana
DNI/NIE: módulo 23 → letra de control
CIF: dígito de control + tabla JABCDEFGHI
Fecha: no anterior a hoy
Email: regex formato + dominio
Capa 2 — Servidor (PHP · FormRequest) siempre, aunque el cliente tenga JS desactivado
8 clases FormRequest independientes
CSRF token en todos los POST
AppRequest → HttpResponseException
Archivos: mimes + extensión + max 10 MB
Respuesta uniforme: {ok, mensaje}
acepta_lopd: required|accepted
